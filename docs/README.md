## Using This Documentation

1. **Start with Business DNA** — Define your brand (name, colors, fonts, values) in the app before creating assets.
2. **Add products to Catalog** — Import from URL or add manually with raw photos.
3. **Pick platform guides** — Read the relevant brand + product docs for your target channels.
4. **Generate assets** — Use Photoshoot and Campaign templates aligned with each platform's specs.

Browse all guides in the app at `/docs`.
